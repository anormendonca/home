# Web Games Collection

Browser-based mini-games built with Vanilla JavaScript, HTML5 Canvas, and Tailwind CSS. Hosted via GitHub Pages.

**Live Site:** [anormendonca.github.io/games](https://anormendonca.github.io/games)

---

## Games

Mafia: Debate and vote each day to eliminate hidden killers before they outnumber the town.

The Impostor Game: Complete real-time map tasks while identifying hidden killers sabotaging the crew.

Fake Artist: Add one stroke per turn to a shared drawing while a clueless imposter tries to blend in.

---

## Tech Stack

* HTML5 / Vanilla JavaScript (ES6+)
* HTML5 Canvas API (Touch & Mouse support)
* Tailwind CSS
* Lucide Icons
* Canvas Confetti
